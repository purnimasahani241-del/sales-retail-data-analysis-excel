Sales and Retail Data Analysis Dashboard using Excel
Project Overview:

This project presents an interactive Sales and Retail Analysis Dashboard built using Microsoft Excel to analyze sales performance and identify key business insights.

Tools Used:

Microsoft Excel
Pivot Tables
Pivot Charts
Slicers for Interactive Filtering
Data Visualization
Dashboard Design

Key Analysis:

Category-wise Sales:  Analyzes sales performance across different product categories.
Sales by Region:   Compares sales across different geographical regions.
Top 10 Product Sales:  Identifies the top 10 best-performing products based on sales.
Sales by Segment:   Evaluates sales performance across different customer segments.
Monthly Sales Trend:  Tracks monthly sales patterns and trends over time.

Interactive Dashboard Features:

The dashboard includes four interactive slicers:

Category
Segment
Region
Payment Mode

These slicers allow users to dynamically filter the dashboard and explore sales performance based on different business dimensions.

Project Objective:

To transform retail sales data into meaningful visual insights, monitor sales performance, identify top-selling products, and support data-driven business decisions.
